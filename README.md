# Ankith S Portfolio

A responsive Next.js, TypeScript, Tailwind CSS and Framer Motion portfolio, ready for Vercel.

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev` and open `http://localhost:3000`.

## Before deploying

- Put the real résumé at `public/Ankith-S-Resume.pdf` so the download link works.
- Replace the placeholder social links in `app/page.tsx` with Ankith's real LinkedIn, GitHub, and email/form-service link.
- Connect the contact form to Formspree, Resend, or another provider; it currently confirms submission in the interface only.

## Deploy to Vercel

Push this folder to GitHub, import the repository in Vercel, and deploy. Vercel automatically recognizes Next.js.
